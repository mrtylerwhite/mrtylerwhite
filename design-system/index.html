Design system

Tailark Dusk ported to plain HTML on Basecoat. Light sections use our warm off-white, dark sections use Dusk's near-black, H1–H4 stay in condensed caps, and our brown is the accent. Everything else follows Dusk 1:1. See the colours.

Browse sections Components

How to use it

Link /assets/css/ds/basecoat.css, add the page to @source in assets/css/ds/basecoat.input.css, then run npm run build:ds. Copy markup from the Code tabs. Put class="dark" or class="light" on each <section>.

Colours

Components only ever use the role names. The section's class decides which palette fills them.

Data & illustration

Charts follow Apple's Health and Stocks idiom: a summary above the plot that follows your pointer, the axis on the right, four light gridlines, and the whole plot as the touch target. Brown is always the result. Illustrations come from Tailark's library (see Bento).

Trend line

Stocks-style: smooth line, soft gradient, time-range switcher, ship date marked. Drag across it or use the arrow keys.

Activity bars

Health-style: rounded bars from zero, optional goal line, the selected bar stays lit while the rest dim.

Before / after

The core ROI comparison. The header leads with the average lift; hovering a task shows its before, after and lift.

Features 1

Dusk's feature cards are intentionally empty abstract compositions: an offset card, a fade panel, a window. Replace a shape with a real screenshot, never with decoration.

Every project, one story.
What changed and why.

One impact view. See every project's baseline, change and owner in one place.

Evidence in context. Metrics, quotes and decisions stay linked to the work, not scattered across decks.

Baselines. Capture the before so the after means something.

Updates. Leaders hear about wins as they land.

Stakeholders. Everyone works from the same numbers.

Trends. Spot the impact before review season.

Bento (Tailark)

Ported from Tailark Quartz bento-1 and bento-2. Not every feature gets the same box: wide tiles carry the main visual, small tiles support the story. Uses a container query, so it adapts to wherever it's placed.
